01Research

FPGA Acceleration of the DistilHuBERT Speech Foundation Model

Energy-Efficient Circuits and Systems Lab, NTU · Advisor: Prof. Tsung-Te Liu · 2025–present

DistilHuBERT is a compressed self-supervised speech model that turns raw audio into general-purpose representations for downstream tasks such as intent classification and speaker identification. I'm building a hardware/software co-design on an Intel Stratix 10 SoC (Apollo S10 SoM), where the FPGA runs the model and the on-chip ARM processor (HPS) drives it.

HPS DDR4→ AXI bridge→ On-chip M20K buffers→ Compute arbiter
  • Architecture: designed layer-by-layer weight streaming from HPS DRAM into on-chip memory, so the whole model runs without fitting all weights on-chip at once.
  • RTL: wrote the bridge controller (Verilog) connecting the accelerator to the HPS over AXI4 / AXI4-Lite, replacing a flat-memory simulation model.
  • Verification: built a multi-layer integration testbench covering every encoder layer, checked against golden reference outputs.
  • Bring-up: took the design from Quartus / Platform Designer through flashing and boot to running on the board, debugging issues across clocking, memory latency, address mapping and the boot flow.
  • Software: turned the testbench flow into a Linux C driver that runs inference from the HPS through memory-mapped AXI.
  • Status: the full model runs on the FPGA with SUPERB downstream heads for intent classification and speaker identification. Current work is timing optimization, more downstream tasks, and sparsity.
VerilogIntel Stratix 10 SoC AXI4QuartusC / Linux HW/SW co-design

This is ongoing lab research, so the source code isn't public. I'm happy to talk through the design in more detail. Just get in touch.
