Research

FPGA Acceleration of the DistilHuBERT Speech Foundation Model

NTU Energy-Efficient Circuits and Systems Lab·2025 – present

A hardware/software co-design that runs a compressed self-supervised speech model on an Intel Stratix 10 SoC. The FPGA runs the model, and the on-chip ARM processor streams weights in and drives inference from Linux.

Read the full write-up
HPS DDR4→AXI bridge→On-chip M20K→Compute arbiter
  • Architecture: layer-by-layer weight streaming from HPS DRAM into on-chip memory, so the full model runs without fitting all weights on-chip at once.
  • RTL: designed the bridge controller (Verilog) connecting the accelerator to the HPS over AXI4 / AXI4-Lite.
  • Verification: a multi-layer integration testbench covering every encoder layer, checked against golden reference outputs.
  • Bring-up: from Quartus / Platform Designer through flashing and boot to running on the board, debugging clocking, memory latency, address mapping and boot-flow issues along the way.
  • Software: a Linux C driver that runs inference from the HPS through memory-mapped AXI.
  • Status: running on the FPGA with SUPERB downstream heads for intent classification and speaker identification. Now working on timing optimization, more downstream tasks, and sparsity.

This is ongoing lab research, so the source code isn't public. I'm happy to talk through the design in more detail.
